# Evaluation datasets

Small, redistributable fixtures may be committed here. Larger or restricted
datasets are ignored and should be documented with a download or generation
procedure.

Tracked datasets are allow-listed by exact name in `.gitignore`; everything
else in this directory is ignored.

- `quality-core-v1.json` — the quality evaluation dataset
  (`schema` = `quality-eval-record/v1`). See
  [`../quality/README.md`](../quality/README.md) for the record format and how
  to add cases.
